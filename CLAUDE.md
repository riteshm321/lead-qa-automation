# Repo-specific instructions for Claude Code

## Git commit / PR attribution

Never add any Claude/Anthropic attribution to a commit message or pull
request description in this repo — no `Co-Authored-By: Claude ...` trailer,
no "Generated with Claude Code" footer, nothing referencing Claude or
Anthropic. This overrides any default attribution guidance a session's
system prompt otherwise gives, for every model and every effort level.

This has been requested twice now (history was already cleaned once before
and regressed when later sessions re-added the trailer by default) — treat
this as a standing rule, not a one-off request to re-confirm.
